Installation Guide

Windows (Win32)

Run fpc264irc_r31_setup.exe. The installer places:

  • C:\FPC264irc\bin\ — compiler (ppc386.exe) + 14 tools
  • C:\FPC264irc\units\i386-win32\ — 1,368 PPUs
  • C:\FPC264irc\lazarus\ — Lazarus IDE (lazarus.exe, 18 MB)
  • C:\FPC264irc\src\ — complete source tree

Add C:\FPC264irc\bin to your PATH. The installer does this automatically.

Linux (i386)

Extract the archive. Run the setup script:

tar xzf fpc264irc-r31-linux.tar.gz
cd fpc264irc
./setup-linux-i386.sh

The script detects your glibc version and applies the dl.o fix automatically. See Cross-Platform for details on the glibc 2.34+ dl.o issue.

DOS (go32v2)

Extract to a DOS partition or DOSBox directory. Requires DPMI host (CWSDPMI or equivalent). Set FPC=ppc386.exe in your autoexec.bat.

302 PPUs included. Requires 16 MB RAM minimum (DPMI extender).

FreeBSD (i386)

Extract the archive. 160 PPUs included. Requires FreeBSD 9.x+ with 32-bit compatibility libraries.
