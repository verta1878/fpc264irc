CORBA Interface Workaround

FPC 2.6.4 doesn't support constref in interface method declarations. The pre-built PPUs were compiled by a newer FPC that uses constref for IUnknown.QueryInterface. Our compiler generates const instead — signature mismatch.

Fix: interfaces that don't need IUnknown (no GUID, no reference counting) are switched to {$interfaces corba}. CORBA interfaces don't require QueryInterface/_AddRef/_Release.
