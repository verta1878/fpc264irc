fpGUI Toolkit

fpGUI is a lightweight cross-platform GUI toolkit included in fpc264irc. 307 Pascal units.

Location

libs/fpgui/

Key Units

UnitDescription
fpg_form.pasForm (window) component
fpg_button.pasButton component
fpg_edit.pasText edit component
fpg_label.pasLabel component
fpg_grid.pasGrid/table component
fpg_tree.pasTree view component
fpg_menu.pasMenu component
fpg_dialogs.pasCommon dialogs
fpg_lcl.pasLCL bridge

Usage

uses fpg_form, fpg_button;

var
  frm: TfpgForm;
begin
  fpgApplication.Initialize;
  frm := TfpgForm.Create(nil);
  frm.WindowTitle := 'Hello fpGUI';
  frm.Show;
  fpgApplication.Run;
end.

vs LCL

fpGUI is simpler and lighter than LCL. Use fpGUI for small tools. Use LCL (Lazarus) for full IDE-designed applications.
