FPC 2.6.4irc — Patch 6: MZ Linker Source Recovery
==================================================
Date: 2026-09-09
From: sysop/0

WHAT:
  Recovered 5 source files for the i8086-msdos internal MZ linker.
  These were backported from FPC 3.2.2 when i8086 support was added
  but never committed to the repo. The prebuilt ppcross8086 binary
  already has them compiled in.

FILES (copy into fpc264irc repo):
  src/compiler/systems/t_msdos.pas    540 lines  MSDOS target linker
  src/compiler/systems/i_msdos.pas    121 lines  MSDOS system info
  src/compiler/ogomf.pas            3,226 lines  OMF + MZ exe output
  src/compiler/omfbase.pas          2,916 lines  OMF format base types
  src/compiler/owomflib.pas           617 lines  OMF library reader

DOCS:
  FPC264IRC-MZ-LINKER.md             Investigation results
  PATCH6-MZ-LINKER-HANDOFF.md        Handoff for .a fallback patch

PENDING:
  The internal MZ linker works but can't find smartlinked .a files
  (looks for .o only). Patch 6b will fix DefaultLinkScript in
  t_msdos.pas to fall back to .a when .o is missing.
  See PATCH6-MZ-LINKER-HANDOFF.md for exact instructions.

APPLY:
  cd fpc264irc
  cp -r patch6/src/compiler/systems/t_msdos.pas src/compiler/systems/
  cp -r patch6/src/compiler/systems/i_msdos.pas src/compiler/systems/
  cp patch6/src/compiler/ogomf.pas src/compiler/
  cp patch6/src/compiler/omfbase.pas src/compiler/
  cp patch6/src/compiler/owomflib.pas src/compiler/

VERIFY:
  All 5 files should match the versions compiled into ppcross8086.
  No rebuild needed until Patch 6b (.a fallback) is applied.
